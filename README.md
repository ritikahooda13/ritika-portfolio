# Ritika Hooda — Personal Portfolio

A responsive, static personal portfolio built with HTML, CSS and vanilla JavaScript.

## Preview locally
Open `index.html` in a browser, or run a local static server from this folder:

```bash
python -m http.server 8000
```

Then visit http://localhost:8000.

## Publish with GitHub Pages
1. Create a new public GitHub repository, e.g. `ritika-portfolio`.
2. Upload `index.html`, `style.css`, `script.js`, and this README to the repository root.
3. In GitHub, open **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**, choose `main` and `/ (root)`, then Save.
5. Wait for GitHub Pages to publish and open the URL shown in Settings → Pages.

## Before publishing
- Verify the LinkedIn and GitHub links.
- Confirm that every project description accurately reflects your work.
- The VibeCheck card intentionally says deployment is pending; replace this with its real public URL only after VibeCheck has been securely deployed and tested.
- Add project repository/demo links when those URLs are available.
